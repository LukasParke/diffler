# @lukasparke/diffler-remotion

Remotion profile graphics for the public stats JSON generated by
[`diffler`](../diffler). The workflow renders animated WebP assets and publishes
them to GitHub Pages, so generated images do not grow the source repository
history. GIF output remains available as an explicit local opt-in.

## Live Assets

Use the Pages URLs from this repository in a profile README:

```md
<img src="https://your-username.github.io/your-repo/readme.webp" alt="GitHub stats" />
```

Available assets:

- `readme.webp`
- `main-stats.webp`
- `stats.webp`
- `repo-impact.webp`
- `languages.webp`
- `top-languages.webp`
- `activity-overview.webp`
- `commit-streak.webp`
- `issue-tracking.webp`
- `code-metrics.webp`

## Data Source

The default input is:

```json
{
  "username": "your-username",
  "statsUrl": "https://raw.githubusercontent.com/your-username/stats/main/github-user-stats.json"
}
```

For a template fork, change `input.json` and the workflow `stats-json-url`
default to your public stats repository.

The renderer supports both the new `schemaVersion: 2` stats output and the old
legacy JSON shape. It refuses to render public assets when the stats JSON
contains private repository details unless `ALLOW_PRIVATE_REPOSITORY_DETAILS`
is explicitly set to `true`.

## Local Rendering

Install FFmpeg with WebP support and make `ffmpeg` available on `PATH`, then run:

```sh
pnpm install
pnpm prepare:stats
pnpm render:all
```

Rendered assets are written to `pages/`, which is intentionally ignored by Git.
Animations are rendered once at their configured dimensions as a high-quality
VP9 master. The pipeline samples that master at 12 FPS for compact animated WebP
output. Run `pnpm render:gif` when a palette-optimized 8 FPS GIF is specifically
required.

## CI Publishing

`.github/workflows/render-video.yml` renders on pushes, daily schedule, and
manual dispatch. It publishes `pages/` with GitHub Pages instead of committing
generated images back to `main`.
